# meshery-schemas (Rust)

Rust models and typed async clients generated from the
[Meshery schemas](https://github.com/meshery/schemas) OpenAPI constructs:
the same bundled specifications the Go models, TypeScript types and
Python client are generated from.

> **Pilot.** This crate covers the same constructs as the Python client
> (`v1beta2/key` today) and is not published to crates.io yet. Its version
> is a placeholder.

## Layout

- `src/<construct>/` is generated by `build/generate-rust.js` with
  [progenitor](https://github.com/oxidecomputer/progenitor). Do not edit it.
  - `mod.rs`: the `Client`, one async method per operation.
  - `types/`: the models, with serde mappings for the camelCase wire format.
- `Cargo.toml`, `src/lib.rs`, this README and `tests/` are maintained by hand.

## Use

```toml
[dependencies]
meshery-schemas = { git = "https://github.com/meshery/schemas", features = ["rustls"] }
```

```rust,no_run
use meshery_schemas::key::Client;
use meshery_schemas::reqwest::header::{AUTHORIZATION, HeaderMap, HeaderValue};

# async fn example() -> Result<(), Box<dyn std::error::Error>> {
let mut headers = HeaderMap::new();
headers.insert(AUTHORIZATION, HeaderValue::from_str("Bearer <token>")?);
let http = meshery_schemas::reqwest::Client::builder().default_headers(headers).build()?;
let client = Client::new_with_client("https://cloud.example.com", http);
let key = client.get_key_by_id(&"00000000-0000-0000-0000-000000000000".parse()?).await?;
println!("{}", key.into_inner().description.as_str());
# Ok(())
# }
```

- **TLS:** the client uses `reqwest` with no TLS backend by default. Enable
  `rustls` or `native-tls` for `https://` on native targets.
- **wasm32:** the crate, client included, builds for
  `wasm32-unknown-unknown`, where `reqwest` uses the browser's `fetch`.
- **Wire behaviour:** an explicit `null` and an absent optional member both
  read as `None`, and `None` is not serialized. Closed schemas
  (`additionalProperties: false`) reject members they do not declare, and
  `maxLength` limits are checked when deserializing.

## Develop

From the repository root:

```bash
rustup toolchain install   # installs the toolchain rust-toolchain.toml pins
make generate-rust         # regenerate src/<construct>/ and .rust-gen-manifest.json
make test-rust             # guard test, fmt, clippy -D warnings, cargo test, wasm32 build
```

See [`docs/schema-tooling.md`](../docs/schema-tooling.md#rust-client-generation-pilot)
for the generator choice, the PR contract and how to add a construct.
